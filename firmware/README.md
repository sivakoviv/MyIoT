# Firmware

Стартовое направление — ESP32-C3 и ESP-IDF. Перед добавлением исходного кода зафиксировать точную плату, назначение выводов, версии SDK и способ сборки.

Требования первой прошивки: безопасный старт выхода, локальные лимиты полива, валидация датчика, STOP, диагностика и OTA A/B с подтверждением загрузки/откатом.
