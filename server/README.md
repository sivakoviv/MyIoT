# Server

Сервисы разворачиваются владельцем проекта: локальный MQTT/API, база событий и конфигурации, хранилище подписанных обновлений и, позднее, адаптер Яндекса.

Не публиковать MQTT-брокер или административный интерфейс напрямую в интернет. Сначала определить, нужен ли собственный интерфейс либо Home Assistant как локальный пользовательский адаптер.
